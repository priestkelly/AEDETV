# Chinyere Udoma Website Recreation

A responsive, multi-page frontend recreation built with plain HTML, CSS and JavaScript.

## Pages
- `index.html` — Home
- `about.html` — About the ministry
- `music.html` — Music and releases
- `booking.html` — Booking enquiry form
- `contact.html` — Contact details and FAQ

## Run locally
1. Extract the ZIP file.
2. Open the folder in Visual Studio Code.
3. Install the free **Live Server** extension (optional).
4. Right-click `index.html` and choose **Open with Live Server**.
   - Or open `index.html` directly in your browser.

## Important notes
- This is an original frontend recreation based on publicly visible page structure and descriptions, not the website's private/original source code.
- Decorative album covers and portrait areas are placeholders. Replace them with photographs and artwork you have permission to use.
- Music links currently point to generic Spotify pages; replace them with the artist's official track/album URLs.
- Booking and contact forms are demo-only. They validate in the browser but do not send or store messages. Connect an authorized backend or form service before publishing.
- Confirm biography, statistics, testimonials, event information and contact details with the website owner before launch.
- The Google Fonts import requires an internet connection; system fallback fonts are included.
